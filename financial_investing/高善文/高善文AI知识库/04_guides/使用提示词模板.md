# 高博 Skill 使用提示词模板

## 1. 标准专题

```text
使用高博宏观—政策—市场分析 Skill 分析【问题】。

截至日期：【日期】
研究时域：【时间尺度】
决策对象：【方向/相对价值/择时/风险控制】
重点资产：【资产】

要求：
1. 先检索 V4 文集方法论和同主题历史文章，使用 V4 文章 ID；
2. 提出至少三个真正竞争的假说，并在取数前写出分歧预测；
3. 至少覆盖三个横断面维度和两个独立证据家族；
4. 做价格—数量、名义—实际或存量—流量拆分；
5. 建立广谱观察矩阵和排他性证据矩阵；
6. 至少两项证据要降低竞争假说权重，并保留一项反向证据；
7. 相关指标按证据簇去重；
8. 排列主导因子、次要因子和当前不可识别部分；
9. 完成政策/资产负债表/广谱利率/资产价格传导；
10. 给出情景、证伪阈值和更新节点。
```

## 2. 主导因子识别

```text
请不要直接给结论。围绕【被解释变量】提出 3—5 个竞争性原因。
先列出各原因在行业、产品、地区、主体、融资渠道和资产价格上的不同预测，再说明需要哪些数据。
根据覆盖面、横断面梯度、时序、持续性、会计闭合和排他性，判断哪个因素更重要。
证据不足时明确写“当前不可识别”。
```

## 3. 排他性证据设计

```text
我的主假说是：【假说】。
请用高博 Skill 做反方审查：
- 提出至少两个竞争假说；
- 写出每个假说互不相容的预测；
- 找出能够提高一个假说、同时降低另一个假说的指标；
- 区分排他性证据、一般支持证据、背景证据和反向证据；
- 避免把同源指标重复计票；
- 给出最有信息增量的下一组数据。
```

## 4. 政策穿透

```text
分析【政策】时，不要停留在政策态度。
请拆解政策原文、相对基线净增量、新增/续作/置换、执行主体、资金来源与运用、资产负债表归宿、执行约束和时滞。
按地区、主体、银行类型、企业所有制/规模和实际使用率做广谱观察，并用排他性证据区分：政策供给不足、执行受阻、私人信用需求不足、债务置换和已被市场定价。
```

## 5. 投资委员会

```text
把现有分析改写为投资委员会版本。
第一页必须回答：主导因子、两项最强排他性证据、最大反证、置信度、已定价程度、推荐表达、风险预算和最短证伪条件。
正文保留竞争性假说表、广谱观察矩阵、排他性证据矩阵、跨资产核对、情景概率和更新节点。
```

## 6. 历史复盘

```text
使用点时原则复盘 V4 文集中的【文章/阶段】。
区分当时可得数据、作者当时判断、后来结果和事后修订；不要用后见之明。
分析其使用了哪些横断面、哪些证据真正具有排他性，哪些只是一般支持；说明今天复用该方法需要补充哪些新数据。
```
