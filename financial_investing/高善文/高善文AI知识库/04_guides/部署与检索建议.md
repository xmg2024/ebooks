# 部署与检索建议

## 一、推荐导入范围

### 最小部署

- `01_skill/高博宏观市场分析Skill.md`；
- `02_markdown_articles/`；
- `05_indexes/article_index_v2.csv`；
- `05_indexes/topic_map_v2.md`；
- `05_indexes/methodology_concept_map.md`；
- `05_indexes/broad_observation_dimension_map.md`；
- `05_indexes/exclusive_evidence_method_map.md`。

### 完整部署

再加入：

- `03_rag_chunks/chunks_semantic_900_120.jsonl`；
- `policy_map.md`、`asset_map.md`、`timeline.md`；
- `legacy_v3_to_v4_map.csv`；
- EPUB 文章和图片索引；
- 8 个 references 与 evals。

## 二、检索优先级

1. 先用方法论、广谱维度和排他性方法索引定义分析设计；
2. 再用主题/政策/资产索引筛选文章；
3. 用语义切片定位章节；
4. 回单篇 Markdown 核对上下文；
5. 涉及图表、表格、脚注和日期时回源 EPUB；
6. 补充当前一手数据后再形成结论。

## 三、建议元数据字段

语义检索系统应保留：

- `article_id`、`title`、`date`、`category`；
- `section_path`、`chunk_id`、`prev_chunk_id`、`next_chunk_id`；
- `topics_v2`、`asset_classes`、`policy_dimensions`；
- `methodology_concepts`；
- `broad_observation_dimensions`；
- `exclusive_evidence_methods`；
- `legacy_v3_ids`、`update_status`；
- `source_epub_sha256`、`body_sha256`。

## 四、召回策略

推荐混合召回：

- 文章标题/关键词召回；
- 语义向量召回；
- 主题与方法标签过滤；
- 日期和分类过滤；
- 文章级重排；
- 相邻切片扩展。

对于因果归因问题，查询应同时包含：

- 主假说关键词；
- 竞争假说关键词；
- 横断面维度；
- 排他性检验词，如“价格数量、行业分化、时序、自然实验、国际比较、资产负债表”。

## 五、旧版迁移

V4 原生 ID 与旧版 ID 不同。对持久化提示词、引用或书签：

1. 用 `legacy_v3_to_v4_map.csv` 批量迁移；
2. 新输出只使用 V4 ID；
3. 旧版被删除的 4 篇不应自动映射到无关文章；
4. 合并稿默认引用 V4 完整版本。

## 六、上下文装配

单次研究建议装配：

- Skill 核心规则；
- 与任务相关的 2—4 个 reference；
- 5—12 篇候选文章的关键章节；
- 每篇关键章节的相邻切片；
- 当前数据、政策原文和价格；
- 明确的假说与证据矩阵模板。

不要一次性把全文全部塞入上下文；这会稀释证据权重并增加错误引用。

## 七、质量控制

生产环境建议对输出自动检查：

- 是否出现至少 3 个竞争性假说；
- 是否有广谱观察矩阵与排他性证据矩阵；
- 是否至少 3 个横断面和 2 个独立证据簇；
- 是否存在“降低/排除竞争假说”的明确字段；
- 是否有反向证据和不可识别说明；
- V4 ID 是否有效；
- 当前事实是否超过文集时点却无外部来源。
