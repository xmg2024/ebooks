# 高博宏观—政策—市场分析 Skill

当前版本：**1.2.0**。

本目录同时提供：

- `gaobo-macro-market-policy/`：标准多文件版；
- `高博宏观市场分析Skill.md`：自动合并的单文件完整版；
- `高博宏观市场政策分析Skill_完整版.md`：同内容的兼容命名副本。

V1.2.0 基于《高善文文集 V4.0》更新，核心变化是将以下两项设为完整研究的硬门槛：

1. **广谱观察**：利用行业、产品、地区、主体、融资渠道、期限评级、收入群体和跨资产等横断面，比较不同经济驱动的覆盖面、梯度、时序和持续性。
2. **排他性证据**：在竞争性假说之间寻找具有分辨力的证据；一项证据必须降低至少一个竞争假说的解释力，才称为排他性证据。

标准版由 `SKILL.md`、8 个 references、回归测试和评分标准组成。运行 `07_tools/assemble_skill.py` 可重新生成两个单文件版本。
